==========================================
  SKINCAPITAL - Suivi d'inventaire CS2
==========================================

DEMARRER
  Double-cliquez sur SkinCapital.exe.
  Une fenetre s'ouvre avec les journaux du serveur, puis votre
  navigateur s'ouvre tout seul sur l'application.

  (Si Windows affiche un avertissement de securite la premiere fois :
   "Informations complementaires" puis "Executer quand meme".
   C'est normal pour une application non signee.)

ARRETER
  Fermez la fenetre SkinCapital (ou Ctrl+C dedans).

PREMIERE UTILISATION
  1. Cliquez sur "Ajouter un compte" et connectez-vous avec votre
     compte Steam (validation sur l'app Steam mobile ou code
     Steam Guard).
  2. L'inventaire se charge, puis les prix arrivent petit a petit.

BON A SAVOIR
  - Vos donnees restent sur VOTRE ordinateur (dossier data\ a cote
    de l'exe).
  - Votre mot de passe Steam n'est JAMAIS enregistre, nulle part.
  - Les reglages (langue, source de prix, heure du rechargement
    automatique, couleur...) sont dans l'application, icone
    engrenage "Parametres".
  - Configuration avancee (port, acces LAN...) : creez un fichier
    .env a cote de l'exe, voir la documentation du projet.
