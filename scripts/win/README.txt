==========================================
  SKINCAPITAL - CS2 Inventory Tracker
==========================================

START
  Double-click SkinCapital.exe.
  A window opens with the server logs, then your browser opens
  on the app automatically.

  (If Windows shows a security warning the first time:
   "More info" then "Run anyway".
   This is normal for an unsigned application.)

STOP
  Close the SkinCapital window (or Ctrl+C inside it).

FIRST RUN
  1. Click "Add account" and log in with your Steam account
     (approval in the Steam mobile app or Steam Guard code).
  2. The inventory loads, then prices come in progressively.

GOOD TO KNOW
  - Your data stays on YOUR computer (data\ folder next to
    the exe).
  - Your Steam password is NEVER stored, anywhere.
  - Settings (language, price source, auto-refresh schedule,
    theme...) live in the app, gear icon "Settings".
  - Advanced configuration (port, LAN access...): create a .env
    file next to the exe, see the project documentation.
